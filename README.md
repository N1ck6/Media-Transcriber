# Локальная расшифровка медиа (на основе faster-whisper)

Программа превращает аудио и видео в текст.<br>
Поддерживает русский язык, батч обработку, папки, форматы txt/srt/vtt, работу как на GPU, так и на CPU.

---

## Подготовка

1. Python 3.10–3.12 (с галочкой Add to PATH).
2. FFmpeg:
   ```
   winget install Gyan.FFmpeg
   ```
3. Виртуальное окружение и зависимости (рекомендуемый путь):
   ```
   mkdir C:\whisper
   cd C:\whisper
   py -3.12 -m venv venv
   venv\Scripts\python.exe -m pip install faster-whisper
   ```
4. Скопируйте `transcribe.py` и `run.bat` в `C:\whisper`.

При первом запуске скачивается модель Whisper (несколько ГБ).<br>
При наличии NVIDIA GPU программа сама установит CUDA-библиотеки (~800 МБ), если их ещё нет.<br>
Без GPU программа работает на CPU (значительно медленнее).

---

## Запуск

Дважды щёлкните `run.bat` или выполните из командной строки.

- ### Без параметров (интерактивный режим)
  Программа запросит пути к файлам.

- ### Файлы сразу
  ```
  run.bat "D:\лекции\1.mp4" "D:\лекции\2.mp4"
  ```

- ### Папка целиком
  ```
  run.bat --dir "D:\лекции"
  ```

### Дополнительные флаги

| Флаг | Описание |
|------|----------|
| `-t` / `--time` | Таймкоды в txt |
| `--lang ru` | Язык (по умолчанию ru) |
| `--model large-v3` | Модель: tiny, base, small, medium, large-v3, turbo |
| `--format txt` | Формат: txt, srt, vtt |
| `--dir ПАПКА` | Обработать все медиафайлы в папке |
| `--output-dir ПАПКА` | Куда сохранять результаты |

Примеры запуска:
```
run.bat "D:\лекции\1.mp4"
run.bat -t --format srt "D:\лекции\1.mp4"
run.bat --dir "D:\лекции" --output-dir "D:\тексты" --format vtt
```
